## 二、A 组：已埋伏笔但未兑现 —— 已完成

共同特征：**配置表或注释里已经承诺了某特性，但代码没有对应实现**，属于「说到没做到」。

### [x] A1 主题只是换色，机制完全一样

**问题**　`LEVELS` 写着「打滑的冰雪赛道」「热浪与流沙」「炽热的生死时速」，但 `THEMES` 只有颜色字段。6 关除配色外手感完全一致。

**实现**　给每个主题增加机制字段并在运行时真正生效：

| 字段 | 含义 | 生效位置 |
|---|---|---|
| `traction` | 抓地力（1.0 正常，越低越飘） | `Player` 横向惯性 |
| `wind` | 逆风强度（0 无风） | `World` 周期性阵风压速 |
| `gap` | 每行出现坑洞的概率 | 地形生成（见 A3） |
| `pit_glow` / `warn` | 坑底发光色 / 预警条纹色 | 地形视觉 |

最终六关配置：

| 关卡 | traction | wind | gap | 路况摘要（游戏内显示） |
|---|---|---|---|---|
| 1 翠绿草原 | 1.00 | 0.00 | 0.00 | 路况良好 |
| 2 金色沙漠 | 0.88 | 0.30 | 0.00 | 地面湿滑、强逆风 |
| 3 白雪旷野 | **0.45** | 0.10 | 0.00 | 地面极滑、阵风 |
| 4 幽暗森林 | 0.92 | 0.00 | 0.17 | 有裂谷 |
| 5 熔岩峡谷 | 0.86 | 0.18 | 0.32 | 地面湿滑、阵风、大量裂谷 |
| 6 极夜冰原 | **0.58** | 0.22 | 0.26 | 地面极滑、阵风、大量裂谷 |

**关键设计**

- **打滑怎么做的**：原来 `velocity.x` 是直接赋值（瞬时响应），改为以有限加速度 `move_toward` 逼近目标，加速度再乘 `traction`。冰面上加速与刹车都变慢，于是**会滑过目标车道再荡回来**，必须提前打方向。
- **同步修正判定**：换道完成的条件从「位置接近」改为「位置接近**且已停稳**」，否则滑行途中会被误判为已到位。
- **安全边界**：新增 `EDGE_MARGIN`，再怎么打滑也不会滑出赛道掉进虚空。
- **逆风可预判**：阵风用 `sin²`（约 7 秒一周期）而非随机数，玩家能摸到节奏；越过阈值时播一次风声，HUD 路况提示同步染成警示色。
- **信息前置**：难度选择界面提前显示本关路况，玩家进关前就知道要面对什么。

### [x] A2 「吃 25 个方块回 1 血」是隐藏机制

**问题**　`_coins_since_heal` 逻辑完整、`HP_HEAL_PER_COINS = 25`，但 HUD 没有任何显示——玩家不知道这机制存在，也不知道还差几个。

**实现**

- HUD 左上新增**回血进度条 + 「再 N 个回血」**文字（血条位置相应下移，避免重叠）。
- 顺带修掉**进度被白白浪费**的问题：原逻辑攒满 25 个就无条件清零，满血时这一轮直接蒸发。改为 `Player.heal()` 返回是否真的回上血，满血则**保持进度封顶**，掉血后立刻兑现。
- 满血且已攒满时进度条转金色并显示「回血就绪」，避免玩家以为卡住了。

### [x] A3 `FALL_DEATH_Y` 是死代码 → 做成坑洞

**问题**　`FALL_DEATH_Y = -8.0` 与坠落判定都存在，但地面是连续整块，**永远掉不下去**，逻辑不可达。

**实现**　把它变成真正的玩法——**坑洞（断崖）**，同时补上了障碍类型的空缺（原来只有「矮栏可跳」「高墙需换道」两类）。

- **地形结构重构**：地面从「每地块一整块」改为**按行切分的独立板块**（`FloorSlab`），单行才能改造成坑洞。仍是零分配、可复用，不影响原有环形队列回收。
- **坑洞不是整行挖空**，而是把地面缩短为近端一段窄「跳台」（`PIT_LEDGE = 2.0`），剩余 `PIT_GAP = 4.0 m` 才是缺口。原因见下。
- **视觉**：悬崖边缘有发光预警条纹；熔岩 / 极夜主题坑底有橙色 / 幽蓝发光面。为此把两侧大地从「一整块」改成**左右两条**，中间留出赛道走廊——否则它会从下方糊住坑洞，深渊变成一条浅黑带。
- **音效**：新增坠落长滑音 `fall`。
- **敌人同步**：所有追兵都会检测并跳过坑洞，否则会出现「凌空跑过深渊」的穿帮。

**可跳越性（本项最关键的约束）**

必须保证任何「难度 × 角色」组合都跳得过，且容错足够宽容：

```
最不利组合 = 悠闲难度(speed 0.85) × 大象(speed 0.90, jump 0.95)
前进速度  = 15.0 × 0.85 × 0.90  ≈ 11.5 m/s
滞空时间  = 2 × (11.5 × 0.95) / 32.0 ≈ 0.68 s
水平跳距  ≈ 7.59 m
```

- 缺口若取满一行 6.0 m → 容错仅 **1.59 m（≈0.14 s）**，接近像素级判定，太苛刻。
- 取 4.0 m → 容错 **3.59 m（≈0.31 s）**，手感宽容。这正是保留 2 m 跳台的原因。

**两个在压测中发现并修掉的「必死地形」**

1. **跨地块相连坑洞**——地块各自独立装填，若允许边缘行挖坑，就会出现「上一块末行 + 下一块首行」相连的 12 m 缺口，任何速度都跳不过去。
   修法：**地块首尾两行永不挖坑**（结构性保证，而非概率规避）。
2. **坑洞落地区有障碍**——跳过坑立刻撞墙，无解。
   修法：坑洞行及其**前后各一行**都不生成障碍。

另外保证：坑洞之间至少留 2 行（12 m）落地缓冲；坑洞正上方不放金币（拿不到），但落地行可以放，奖励敢跳的玩家。

### [x] A4 `_last_result` 写了从没被读

**问题**　`Main._finish()` 构造了一个 5 字段字典 `_last_result`，全项目无任何读取方——纯死代码。

**实现**　删除字段与赋值块。顺带删掉本次开发中一度引入、后因方案调整而失效的 `PIT_WARN_ROWS`——A4 本身就是清死代码，不能自己又留一个。

### [x] A5 「追兵更凶」体感弱

**问题**　难度表描述「追兵更凶」，但所有追兵共用同一套 AI，只有模型和速度不同，玩家感知不到差异。

**实现**　抽出 4 种**行为原型**（`ENEMY_KINDS`），按「凶悍度」加权随机：

| 原型 | 特征 | 关键参数 |
|---|---|---|
| **追猎者** runner | 基准行为 | — |
| **冲刺者** sprinter | 周期性爆发提速，制造「突然被逼近」的紧张感 | `burst 0.42`，爆发时加速度翻倍 |
| **封路者** blocker | **预判**玩家换道方向，抢先堵在他要去的车道 | `think 0.55`（反应最快）、`lane_switch 1.45`、`miss 0.06`（几乎不失误） |
| **跳跃者** jumper | 遇矮栏直接起跳而非绕路，威胁性更强 | `can_jump true` |

- **动态权重**：凶悍度 = `跑动进度 × 难度追兵倍率`。实测低强度下追猎者占 44%，高强度降至 17%，狠角色显著变多。
- **可识别性**：非基准原型头顶带**发光色标**（俯视一眼可辨），基准型不加标记以免画面太吵。
- 跳跃者的跳跃是纯动画位移，不参与物理。

## 三、B 组：玩法深度 —— B1~B3 已完成

> 曾是最大短板，决定「值不值得反复玩」。B1~B3 落地后形成「跑得久」与「玩得花」两条并行追求线。

### [x] B1 无限模式 / 每日挑战

**实现**

- **入口**：关卡地图下方新增两个特殊节点——「∞ 无限模式」与「每日挑战」。关卡索引用负数（-1 / -2），与正常关卡天然隔离，记分键 `"-1_normal"` 直接复用现有 `best_scores` 字典，无限模式也有自己的最佳成绩。
- **无限模式**：`target_distance = INF`，去掉通关判定，纯生存。主题每 500 m 按关卡表顺序轮换（草原 → 沙漠 → 雪 → 森林 → 熔岩 → 极夜 → 循环），已生成地块在回收重装填时自然换色，形成过渡带；障碍密度（0.5→0.8）与敌人上限（2→4）随里程持续爬升。
- **每日挑战**：同一天全世界拿到同一张图（`_rng.seed = hash(日期)`），当日最佳成绩单独记录（`daily_best`，只保留最近 30 天）。难度选择界面显示今日最佳，方便自我挑战。
- **界面适配**：难度界面按模式显示不同说明；结算界面无限模式标题为「无尽征途结束」、距离行无目标值；HUD 进度标签只显示里程，小地图终点旗换成 ∞；主循环切段时通过 `stage_changed` 信号刷新 HUD 的关卡名与路况。
- 生涯统计与成就照常累积（「累计 10km」「单局 2000m」在无限模式天然可达成）。

### [x] B2 道具系统

**实现**　四种道具，完全复用金币的对象池 + `Area3D` 基建（`_powerup_pool` / `_create_powerup` / `_place_powerup`）：

| 道具 | 效果 | 时长 |
|---|---|---|
| 磁铁 | 7 m 半径内的能量方块朝玩家飞 | 8 s |
| 护盾 | 抵挡一次伤害（不掉血、不减速、不计入无伤统计） | 一次性 |
| 双倍分数 | 期间得分整体 ×2 | 10 s |
| 冲刺 | 速度 ×1.35、穿过障碍、FOV 50→62 强化速度感 | 4 s |

- **生成**：每块地形 18% 概率出一个，避开障碍行与坑洞附近保证能吃到；颜色 + 长宽高区分类型，附 7 m 高发光光柱便于远处识别。
- **护盾细节**：视觉是身周半透明能量壳；被击碎时屏幕闪青光（与受伤红光区分）、播破碎音，并附 0.6 秒无敌防止连撞。
- **冲刺细节**：穿透状态与无敌共用统一的碰撞掩码规则（`_update_collision_mask`），避免与受击无敌互相覆盖。
- HUD 左上新增道具状态行：限时道具显示剩余秒数，护盾常驻显示。
- 音效新增 `powerup` / `shield_up` / `shield_break`（共 26 个音色）。

### [x] B3 连击 / 技巧计分

**实现**　分数 = 距离 + 方块 + **技巧分**（`trick_score` 独立累加），「玩得好」与「活得久」解耦：

| 技巧 | 判定 | 分值 |
|---|---|---|
| 连击 | 4 秒内连续拾取方块，每级追加 | 每级 +2 |
| 跳栏 | 滞空区间越过矮栏且横向贴近 | +25 |
| 擦身而过 | 高墙/大方块落到身后时横向距离 1.2~2.6 m 且人在地面 | +15 |
| 飞越坑洞 | 滞空区间覆盖坑洞缺口 | +30 |

- 连击越高，单次技巧奖励越大（×(1 + 连击×0.05)），形成「保持连击 → 技巧更值钱」的正循环。
- 擦身判定刻意排除矮栏与空中状态（空中的奖励归跳栏），避免双重计分。
- HUD 方块计数旁显示 `×N` 连击（等级越高越金），结算界面新增「最高连击」与「技巧得分」两行。
- 新增 `trick` 音效，音高随连击爬升。

## 四、C 组：元进度与动力 —— C1~C3 已完成

共同特征：**局内收集的一切在局外毫无沉淀**。本组三项已落地，形成「跑 → 攒货币 → 解锁角色 → 再跑」的留存闭环。

### [x] C1 总货币 + 商店（角色解锁）

**问题**　收集的 coins 局外全部丢弃；6 个角色一开始全解锁，角色界面没有任何进度钩子。

**实现**

- **货币沉淀**：局内收集的能量方块在结算时 1:1 转为总货币 `coins_total`，结算界面显示 `+N（累计 M）`。
- **角色定价**（`CHARACTERS.cost`）：熊猫免费，兔子 400 / 老虎 600 / 狐狸 800 / 企鹅 1000 / 大象 1200。按一局 200~600 方块的产出估算，集齐全员约需 15~20 局，是健康的留存曲线。
- **商店即角色界面**：未解锁角色卡片覆盖半透明遮罩 + 「解锁：N 能量方块」价格牌；点击即购买（余额足够 → 解锁并自动出战、播解锁音；不足 → 提示还差多少，不扣钱）。不再单独做商店页，少一层导航。
- **旧档迁移**：老存档选中了未解锁角色时自动回退熊猫；存档对角色 id 做了合法性过滤（配置表里不存在的 id 会被剔除，熊猫永远在列）。
- 买复活（C4）与道具购买（B2）留待对应条目，货币基建已就绪。

### [x] C2 生涯统计

**实现**　`GameState` 新增 `stats_*` 累加字段，由统一的 `record_run()` 在每局结算时写入：总局数、总里程、总方块、最远单局、无伤通关次数、噩梦通关次数、各关通关次数（`level_clears`）。新增「生涯」界面（主菜单入口）展示全部数据。

## 五、D 组：手感与表现力 —— D7 已完成

### [x] D7 长按方向键连续变道（插入优化，2026-09-06）

**问题**　方向键只响应「按下沿」（`_handle_key` 里 `not event.echo` 忽略系统重复事件），想连续变道只能疯狂点按，高速路段（46 m/s）根本来不及。

**实现**

- **两段式节奏**：按下立即换一次道；继续按住经过 0.26 s 起始间隔后，每 0.16 s 连续变道。起始间隔刻意略长，想单次变道时不会误触连换。
- **自建计时而非依赖系统重复率**：系统 key repeat 因平台 / 系统设置而异，不可控；用物理帧自己计时（`_hold_dir` + `_hold_cd`），手感在任何机器上一致。
- **边缘静默**：到赛道边缘后连续触发无害——`_change_lane` 撞边时 `target_lane` 不变也不出声。
- **状态残留修复**：松开事件的处理提到 `alive / paused` 守卫之前——否则暂停或死亡期间松键会被拦掉，恢复后角色会「自己跑起来」。快落（S/↓）的取消同理。
- 触屏滑动不受影响；冰面主题下连续变道仍受 `traction` 惯性约束，保留打滑手感。

> 验证：9 项自动化断言全部通过（按下立即换道 / 长按连续 / 边缘停住 / 松开停止 / 短按不连发 / 双向 / 死亡期间松键清理）。
