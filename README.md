# 方块动物 · 大逃亡（RunningRunning）

一款基于 **Godot 4.7** 的 3D 跑酷生存游戏：被追兵盯上的方块动物，在五车道赛道上狂奔求生。跨越坑洞、躲开障碍、收集能量方块回血，跑完 6 个风格迥异的关卡。

## 特性

### 六大主题关卡，机制各不相同
每一关不只是换配色，`traction / wind / gap` 等机制参数真正改变了手感：

| 关卡 | 主题 | 路况特性 |
|---|---|---|
| 1 | 翠绿草原 | 路况良好 |
| 2 | 金色沙漠 | 地面湿滑、强逆风 |
| 3 | 白雪旷野 | 地面极滑、阵风 |
| 4 | 幽暗森林 | 有裂谷 |
| 5 | 熔岩峡谷 | 地面湿滑、阵风、大量裂谷 |
| 6 | 极夜冰原 | 地面极滑、阵风、大量裂谷 |

- **打滑**：低抓地力路面换道会滑过头再荡回来，必须提前打方向
- **逆风**：约 7 秒周期的阵风压低速度，可以摸到节奏提前预判
- **坑洞**：横跨全赛道的断崖必须跳过去，悬崖边缘有发光预警条纹，熔岩 / 极夜主题坑底带发光面
- **横杆**：悬在半空的紫色发光栏杆，跳不过去，只能**滑铲**从下方穿过
- **动态障碍**：左右往复平移的障碍，以及周期性沉入地面 / 升起的开合闸门，节奏固定可预判

### 四种追兵 AI 原型
| 原型 | 特征 |
|---|---|
| 追猎者 | 基准追击行为 |
| 冲刺者 | 周期性爆发提速，制造突然被逼近的紧张感 |
| 封路者 | 预判你的换道方向，抢先堵住去路 |
| 跳跃者 | 遇矮栏直接起跳而非绕路 |

凶悍角色会随跑动进度与难度逐渐增多，非基准原型头顶带发光色标便于识别。

### 六个可选角色
熊猫（均衡）、老虎（极速 -1 血）、兔子（灵巧）、狐狸（高机动）、企鹅（稳健 +1 血）、大象（坦克 +2 血），速度 / 跳跃 / 换道 / 生命各有权衡。

### 四档难度
悠闲散步 / 标准逃亡 / 亡命狂奔（得分 ×1.5）/ 噩梦模式（得分 ×2.2），影响生命、速度、障碍与追兵密度。

### 其他
- **复活 / 续关**：被追上后可消耗 300 能量方块原地满血续命（每局 1 次，6 秒倒计时决定）
- **28 个程序化合成音色**，零音频素材依赖
- 地形为无限环形队列 + 对象池，零运行时分配
- 桌面 + 移动端双操作方案
- 吃 25 个能量方块回复 1 点生命，HUD 实时显示回血进度

## 操作

**键盘**

| 按键 | 动作 |
|---|---|
| `←` / `A`、`→` / `D` | 左右换道（长按连续变道） |
| `空格` / `↑` / `W` | 跳跃（带输入缓冲） |
| `↓` / `S` | 地面滑铲 / 空中快速下落 |
| `R` | 被追上后原地复活 |
| `ESC` | 暂停 |

**移动端**：左右滑动换道，上滑或轻点跳跃，下滑滑铲（空中则快速下落）。

## 运行

1. 安装 [Godot 4.7](https://godotengine.org/)（标准版即可，无需 .NET）
2. 用 Godot 打开 `animalrunning/project.godot`
3. 按 `F5` 运行；也可命令行附加 `--auto-start` 跳过菜单直接开局

## 项目结构

```
animalrunning/
├── project.godot          # 项目配置（Mobile 渲染后端 + Jolt 物理）
├── scenes/main.tscn       # 主场景
├── scripts/
│   ├── game_config.gd     # 全部数值配置：想调平衡只改这个文件
│   ├── game_state.gd      # 存档与进度
│   ├── main.gd            # 总控状态机（菜单 → 对局 → 结算）
│   ├── world.gd           # 地形生成（坑洞/横杆/动态障碍/主题机制）
│   ├── player.gd          # 玩家（打滑/跳跃/滑铲/受击/回血/复活）
│   ├── enemy.gd           # 追兵 AI（四种原型）
│   ├── hud.gd  sfx.gd     # HUD（含复活面板）/ 程序化音效
│   └── screens/           # 主菜单、角色与难度选择、关卡地图、结算
├── models/animals/        # 24 个动物模型（Kenney Cube Pets）
└── docs/                  # 开发文档
```
